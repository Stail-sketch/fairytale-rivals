# 原作カード一対一対応表

ベーシックから第3弾まで、確認できた原作のデッキ用カード573種にFT IDを割り当て、試遊版に収録した。
カード種別、MP、攻撃力、HPまたは耐久力、職業、レアリティ、能力、対象と相互作用の確認状況は[構造化データ](card-correspondence.json)を参照。
原作の公式内部IDは入手できた資料では未確認。保存目録・個別データベースの管理IDと原作パック・原作名を対応キーとして記録する。

| セット | デッキ用収録数 | 集計の根拠 |
| --- | ---: | --- |
| ベーシック | 86 | 保存目録の88件のうち、初期資料で第1弾に掲載された2件を第1弾として収録 |
| 第1弾 スタンダードパック | 287 | 保存目録284件、初期資料で第1弾に掲載された2件、別資料で確認した1件 |
| 第2弾 解き放たれし力の咆哮 | 100 | 保存目録99件と、別資料で確認した「まものの呼び笛」 |
| 第3弾 不死鳥と大地の命動 | 100 | 保存目録100件と個別カード資料 |
| 合計 | 573 | 共通と7職業を含む |

第2弾はデッキ用100種に、対戦中の生成カード7種を加えて107種類。原作で同名の「ネルゲルの配下」には3/3と5/5があり、試遊版では両方を個別の絵とカードIDで表示する。第1弾は後年のグランプリ対象数として260種との記録もあり、試遊版は初期資料と保存目録から確認できた収録範囲を採用した。[第2弾のメーカー発表](https://www.famitsu.com/news/201802/23152459.html) · [保存目録](https://dqrdb.com/) · [原作カード別資料](https://gameconductor.com/dqrivals/card/) · [第1弾のグランプリ対象数の記録](https://www.sadalablog.com/entry/dqr/rankmatch/2rule)

「魔力開放」は「魔力解放」と同じカードとして照合したため、予約していたFT-0123は既存のFT-0008を参照する。別資料で確認した2件にはFT-0473とFT-0474を割り当てた。収録や数値の版差は各レコードの `archive`、`sourceVariances`、`alternativePrintedStats` に残している。

実装ステータスの `tested` は対戦中の使用と処理を自動テストしたことを示す。資料で確認できない効果の同時誘発、対象を選べない局面、版違いの細かな裁定は `unverifiedInteractions` と[裁定ノート](rulings.md)に記録した。

第4弾の通常カード100種と生成・選択用14件は[候補一覧](fourth-pack-candidates.json)に記録した。採用版と効果の確認は[準備資料](fourth-pack-plan.md)に従って進め、確認後に実装用の対応表へ反映する。
