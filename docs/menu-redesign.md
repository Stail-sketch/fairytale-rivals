# ホーム・対戦準備・フレンドロビー

承認された紺と金のデザイン案を、実際に操作できるHTML/CSS/SVGの画面に実装した。リーダーの名称・職業・肖像、カード性能、対戦ルール、データの保存形式は維持する。

- ホーム：左ナビ、選択中のリーダー、使用デッキ、対戦ボタン、現在のRP・戦績、第4弾への案内、音楽室。
- 対戦準備：ランク・フリー・CPU・フレンドのタブ、選択デッキのカード絵、デッキ変更用の開閉欄、対戦形式の説明。CPUの相手選択と同じPCで2人の対戦も引き続き使える。
- プロフィール：ヘッダーの名前から開くダイアログ。未登録でオンライン対戦を始めた場合も開く。画面に入力欄を常設しない。名前変更によってデッキやRPを削除しない。
- 検索：専用画面にリーダー、デッキ名、待機時間、キャンセル。検索中に別の対戦を始めないようナビを無効化する。
- フレンドロビー：自分を左、相手を右に表示。ロビーID・招待URL・クラス・準備状態を表示し、自分だけデッキを変更できる。相手のデッキ内容は表示しない。ホストだけが二人の準備完了後に開始できる。既存の再戦・同一ロビーへの復帰・闘技場ピックにも対応。
- 招待URLのコピーが使えない場合は表示欄を開き、手動でコピーできる。
- 画面が狭い場合はナビを上段に置き、対戦者パネルを縦に並べる。モバイルのホーム・準備・ロビーで横へのはみ出しを検査する。

`apps/web/menu-ui.js` は表示、`main.js` は既存のデータ・イベントと接続する。メニュー専用のCSSを使い、対戦盤面やカードライブラリのレイアウトを変更しない。新しい図書館背景の制作情報と生成プロンプトは `artwork/menu/manifest.json` に保存する。

検証：`tests/menu.e2e.js` にプロフィール保存、既存デッキ保持、デッキ変更、ランク検索とキャンセル、二人のロビー、準備状態、390px表示の検証を追加した。既存の総合操作・通信・BGM試験も新しいホームからの導線を通して実施する。
