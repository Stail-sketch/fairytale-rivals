# 第4弾「刻印に集う、おとぎの一族」

通常カード100種類と、生成カード・願いの選択肢14種類を収録する。
既存の7人のリーダー、10種族、カード能力名を維持する。
露珠・竜鱗・夜継ぎ・銀環・星路はイラストの一族表現であり、新しい種族を追加するものではない。
効果の対象には、これまでの対応表と同じ内部系統を使う。

## 性能の採用版

第4弾は[DQRDBのカード画像](https://dqrdb.com/)のスナップショットを採用した。
GameConductorの一覧値と混ぜて独自の強さに調整しない。
17件の通常カードの数値差は `fourth-pack-candidates.json` の `alternativeStats` に残した。
変身後のアウルも、画像に従って各形態を4MPにする。
対応ID・採用値・画像資料へのリンク・実装状況は `fourth-pack-implementation.json` にまとめる。
資料側の参照IDを、原作の公式カードIDであるとは扱わない。公式IDの確認状態は引き続き未確認とする。

画像照合で一覧テキストから補正した主な処理は、以下のとおり。

| カードID | 採用した処理 |
| --- | --- |
| FT-0582 | 攻撃力+1。最大MPが相手以下なら、さらにHP+1 |
| FT-0586 | 1ダメージ。最大MPが相手以下なら3ダメージ |
| FT-0587 | 復活する夜継ぎの一族はコスト1以下。同じマスに復活 |
| FT-0589 | 通常1体、最大MPが相手以下なら2体を出す |
| FT-0593 | 最大MPが相手以下なら、選んだ手札の竜鱗の一族のコスト-2 |
| FT-0597 | ターン開始時の変身条件は攻撃力6以上 |
| FT-0605 | 背水のかまえとの対応。HP15未満を回復しない |
| FT-0622 | 覚醒でコスト-1。選んだ味方の前衛または後衛を埋める |
| FT-0634 | 登場時の一度きりの強化ではなく、場にいる間の常在型能力 |
| FT-0662 | 正面への分岐は敵ユニットに3ダメージ。敵リーダーを含めない |
| FT-0673 | 引いたカードのコスト-6 |

## 共通処理

- **物語の刻印**：リーダーの対戦状態に保存する。発動元の退場後も続き、同じ効果は重複する。解除はランダムな刻印1つを対象にする。
- **系統強化**：場の攻撃力・最大HP・キーワードと、手札のコストをそれぞれ計算する。生成・復活・変身・支配変更でも再評価する。
- **カード使用と生成**：ユニットカードを使ったときの刻印と、ユニットが場に出たときの武器能力を区別する。
- **変身**：アウルの4形態と、退場した竜鱗の一族を参照する竜詩の姿を実装する。
- **奥義変更**：3種類の変更先を保持し、表示・CPU・フレンド戦・保存復元で同じ定義を使う。
- **4つの願い**：通常は1つを選択し、未来の統合中は4つを順に解決する。
- **鋼の身（強化）**：1〜5ダメージを1にする。常在型の強化と、武器が自分のターン中だけリーダーを守る処理を含む。
- **毒**：原作資料との照合により、自分と相手の両方のターン終了時に1ダメージとした。[特性資料](https://gameconductor.com/dqrivals/tokusei/detail/?no=2)

## 画面と保存

カードライブラリとデッキ編集の収録フィルターに第4弾を追加し、原作名・種類・レアリティで検索できる。
関連カードと用語ポップアップは既存の共通表示を使う。
双方のリーダー付近に刻印の数を出し、マウスオーバーまたはクリックで内容を確認できる。
奥義変更の説明と、刻印・覚醒による強化値の内訳も表示する。
闘技場の候補にも通常カード100種類を追加する。生成カードは構築・闘技場の直接の収録候補にしない。
既存のプレイヤー名・保存デッキを置き換える移行は行わない。

## 検証

`tests/fourth-pack.test.js` は100種類の使用、次ターンまでの進行、主な相互作用、全7職業のCPU対戦を確認する。
`tests/online.e2e.js` では第4弾の刻印を実際の対戦APIで使用し、双方の公開状態と手札の分離を確認する。
全カード・全組み合わせの裁定を網羅したという意味ではない。新しい問題が見つかった場合は個別テストを追加する。
公開前には全原画・配信用画像の一対一対応、画像の重複、ブラウザー操作、Cloudflareでの通信対戦を確認する。

画像の生成プロンプトは `fourth-pack-creative.json` に保存し、原画は `artwork/set-4`、配信用WebPは `apps/web/assets` に保存する。
制作には内蔵のImageGenを使う。
