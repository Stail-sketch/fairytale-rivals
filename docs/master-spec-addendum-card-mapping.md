# マスター仕様追補　原作カード一対一対応

## 適用範囲

ベーシック、第1弾『スタンダードパック』、第2弾『解き放たれし力の咆哮』、第3弾『不死鳥と大地の命動』の職業専用カードと共通カードに適用する。第4弾以降は段階的に追加する。

## 対応と検証

1. 原作カードの消費MP、攻撃力、HP、種別、職業、レアリティ、キーワード、能力の数値・発動条件、対象選択、処理順、特殊な相互作用を調査する。セットごとの種類数と職業・レアリティ構成も調査する。
2. 原作カードと童話戦記のカードを一対一で紐づけ、内部資料で出典・原作ID・FT ID・実装状況を追跡する。原作IDや裁定を確認できない場合は未確認として残す。原作の性能や収録単位は独断で変更・統合・削除しない。
3. 共通能力エンジンを整え、検証用カードでテストしたうえで対象セットを段階実装する。原作の確認状況と、童話戦記側の未実装・実装済み・テスト済みは別の項目として管理する。
4. 名称、キャラクター、イラスト、音楽、世界観、UI素材には童話戦記の新規制作素材と確定済みの設定・用語を用いる。
5. 公開・配布前に知的財産権と利用条件を確認する。必要に応じてゲーム体験を保った独自設計への変更を検討する。
