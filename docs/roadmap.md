# 実装ロードマップ

- Phase 0 [x] モノレポ、状態・コマンド・効果の型、カードデータ、ローカル開発サーバー、テスト環境
- Phase 1 [x] 盤面・ターン・MP・熱量、合法手の検証、30枚の固定デッキ、マリガン、効果処理、勝敗、対面試遊
- CPU対戦 [x] 7人から選択、CPUの手札交換とターン自動操作、7人分の構築済み30枚デッキ
- 奥義・閲覧 [x] 7人の奥義、奥義で生成される8種、カードライブラリと奥義一覧
- 原作カード一対一対応 [x] ベーシック86種、第1弾287種、第2弾100種、第3弾100種を実装・テスト。共通と7職業を含む。資料間の版違いと個別相互作用の照合を継続
- デッキ編集 [x] クラス別の新規作成、名前付きの複数保存、旧デッキの引き継ぎ、収録・名前・効果による検索、対戦前に使用デッキを選択
- Phase 2 [x] 招待URLでのフレンド対戦、同じタブでの再接続、第3弾の舞台の同期
- Phase 3 [進行中] デッキ編集とカード一覧を公開。設定、リーダーごとのバランス検証、操作感の改善を継続
- Phase 4 [進行中] ベーシックと第1〜第3弾の保存資料で確認した全件を収録。第3弾の舞台8種、生成カード11種、六色による特殊勝利を実装。第4弾以降は後続
- 第4弾準備 [進行中] テーマ「刻印に集う、おとぎの一族」と新能力名「物語の刻印」を確定。通常カード100種と生成・選択用14件の候補を記録。FT-0575〜FT-0674を予約し、17種の数値差を記録。[準備資料](fourth-pack-plan.md)に従って効果・採用版を照合し、共通能力から実装する。
- Phase 5 [進行中] 実装済みの648種に専用イラストを用意。リーダー演出、効果音、パフォーマンスを継続

Phase 1には試遊開始時の簡易リーダー選択と、対戦中のカード詳細・イベント履歴を含む。決定済みの仕様は原本を参照する。
