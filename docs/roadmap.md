- Phase 0 [x] モノレポ、状態・コマンド・効果の型、カードデータ、ローカル開発サーバー、テスト環境
- Phase 1 [x] 盤面・ターン・MP・熱量、合法手の検証、30枚の固定デッキ、マリガン、効果処理、勝敗、対面試遊
- CPU対戦 [x] 7人から選択、CPUの手札交換とターン自動操作、7人分の構築済み30枚デッキ
- 奥義・閲覧 [x] 7人の奥義、奥義で生成される8種、カードライブラリと奥義一覧
- 原作カード一対一対応 [x] ベーシック86種、第1弾287種、第2弾100種、第3弾100種を実装・テスト。共通と7職業を含む。資料間の版違いと個別相互作用の照合を継続
- デッキ編集 [x] クラス別の新規作成、名前付きの複数保存、旧デッキの引き継ぎ、収録・名前・効果による検索、対戦前に使用デッキを選択
- Phase 2 [x] 招待URLでのフレンド対戦、同じタブでの再接続、第3弾の舞台の同期
- Phase 3 [進行中] デッキ編集とカード一覧を公開。設定、リーダーごとのバランス検証、操作感の改善を継続
- Phase 4 [進行中] ベーシックと第1〜第4弾の保存資料で確認した全件を収録。第3弾の舞台8種、生成カード11種、六色による特殊勝利を実装。第5弾以降は後続
- 第4弾 [実装・検証完了／公開反映保留] 通常100種類＋生成・選択14種類、物語の刻印、変身、奥義変更、願いを実装。専用画像114枚を組み込み、782件の自動テストを完了。[実装記録](fourth-pack-release.md)・[公開前の確認状態](fourth-pack-rights-review.md)。
- 第4弾の名称・原画 [完了] [名称114件](fourth-pack-names-and-art.md)と[原画114枚](../artwork/set-4/index.html)を制作・組み込み。
- Phase 5 [進行中] 実装済みの762種に専用イラストを用意。リーダー演出、効果音、パフォーマンスを継続
- 対戦開始演出・BGM [設計確定／未実装] 本と札で先攻・後攻を約2秒で見せ、結果表示から全7人のキャラ曲のうち1曲を流す。手札交換と戦場で曲を継続し、フレンド戦は楽曲IDを共有。[設計書](battle-opening-and-bgm-design.md)を参照。
