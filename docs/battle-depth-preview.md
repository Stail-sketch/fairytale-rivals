# 2.5D盤面と開発用試遊

ユーザーの公開指示により、背景ありの拡大表示・効果マーク・レアリティ枠を通常の対戦画面に適用する。既定は立体盤面で、「立体盤面」ボタンから従来表示にも切り替えられる。選択は専用キー `fairytale-battle-board-style-v1` に保存し、既存デッキやプロフィールのキーには触れない。

以下の初期配置を使う試遊モードは、引き続きローカル開発専用。

## 開く

プロジェクトフォルダーで `npm run dev:preview` を実行する。

- 試遊盤面：<http://127.0.0.1:4185/?battlePreview=depth&demo=1>
- 通常のCPU戦：<http://127.0.0.1:4185/?battlePreview=depth>
- 通常画面：<http://127.0.0.1:4185/>（対戦中の「立体盤面」で従来表示にも切り替えられる）

サーバーを終了するときは起動したターミナルで Ctrl+C。再起動も同じコマンドで行う。別ポートは環境変数 `FAIRYTALE_PREVIEW_PORT` で指定できる。

## 試す内容

試遊盤面は双方を手動操作できる。最初からユニットを並べてあり、全カードを背景ありの既存絵と台座で表示する。ユーザーの指定により、背景あり表示を従来の試作からひと回り拡大した。双方は10MP。ユニットの攻撃力・HP・キーワードはカード定義のまま。

1. 前衛の「真鍮の従者」を選び、相手前衛の「真鍮の従者」を攻撃する。踏み込み・着弾・反動を確認する。
2. 手札からユニットを選び、空きマスに召喚する。台座・影・着地を確認する。
3. 騎士の誓いの表示、カードの詳細表示、攻撃対象・配置先の表示を確認する。
4. 「立体盤面」を切り替えて従来表示と比較する。HP・カード・ターンは変化しない。
5. 「短い演出」を押して待機モーションの停止を確認する。OSの動きを減らす設定にも従う。
6. ターン終了で相手側を操作し、盤面と手札が切り替わり、画像自体の向きは維持されることを確認する。
7. ヘッダーの「試遊盤面をリセット」で元の配置へ戻す。

## 効果マークとレアリティ

背景ありの絵と手札の枠を、ベーシックは落ち着いた灰、ノーマルは銀灰、レアは青、スーパーレアは紫、レジェンドは金で区別する。レア以上は盤上の絵の上部にも宝石飾りを付ける。枠はユニットの選択・攻撃可能・対象の表示と別の位置に表示する。

効果マークは防御系が青、攻撃系が橙、不利な状態が赤、能力値変化が緑。無効状態には灰色と斜線、期限付きの防護には時計、付与された能力には＋を添える。攻撃力や最大HPが変わった場合は能力値変化として説明し、被弾による現在HPの減少だけでは強化マークを出さない。

マークにカーソルを合わせると名前と状態を表示し、クリックすると説明が開く。クリックによって攻撃・召喚を選択しない。「効果マーク」ボタンから一覧とレアリティの見本も読める。多数の能力は6枠までに収め、残りをまとめて表示する。これらは立体表示で有効になり、従来表示の配置を保つ。

通常のCPU戦でもプレビュー表示を試せる。全カードの背景と元の絵の向きを維持し、台座付き表示に統一する。敵味方で画像は反転しない。追加の画像生成は不要。

## 保存データ・公開との分離

立体表示は公開ドメインでも既定で有効。試遊機能の `depthPreviewAvailable` は localhost / 127.0.0.1 / [::1] で `battlePreview=depth` を明示した場合だけ有効になる。公開ドメインでは同じクエリを付けても試遊ボタンや試遊用初期配置は有効にならない。試遊用APIとフィクスチャーは開発サーバーだけに存在し、Cloudflareの公開APIには追加しない。

試遊盤面は保存済みデッキを読み書きしない。名前やランクを登録する必要はなく、オンライン待機列にも入らない。公開サイトとlocalhostはブラウザーの保存領域が異なる。自分のデッキでCPU戦を試す場合は、既存のデッキ書き出し・引き継ぎ機能を使える。

## 素材と実装

- 共通表示：床の奥行き、厚い盤面、台座、接地影、待機、踏み込み、被弾、着地。
- 攻撃命中までの時間：通常・レジェンドとも既存の135msを維持。
- 4種類の透過素材は比較用として保存しているが、現在の表示では使用しない。
- `apps/web/battle-depth.js`：表示切り替えと背景ありユニット表示。
- `scripts/battle-preview.js`：開発専用の試遊状態。
- `artwork/battle-depth/manifest.json`：制作プロンプト・出力ファイルの対応。PNG原画も同じフォルダーに保存する。

テスト：`tests/battle-depth.test.js` と `tests/battle-depth.e2e.js`。公開ドメインでの立体表示、試遊機能の制限、設定の保存、元の能力・数値、全ユニットの背景・元絵・向きの維持、実際のクリックによる攻撃・召喚・ターン交代、表示比較、短縮設定、モバイル、既存デッキ保持を確認する。通信対戦とVFX試験でも立体表示と説明ポップアップを確認する。
