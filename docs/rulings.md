# 裁定と出典

本作の確定値は[マスター仕様 v1.0](master-spec-v1.0.md) に従う。以下の暫定実装は試遊を目的とする。原作の挙動について一次資料で確認できていない項目には `UNVERIFIED` を付けた。

## 一次資料で確認できた範囲

- スクウェア・エニックスの公式告知ではオンライン交互ターン制を確認できる。[正式サービス開始告知](https://www.dragonquest.jp/topics/detail/2693/)
- 開発元のCEDEC講演資料では前衛／後衛を含む対戦画面、最大MP、テンションスキル等を確認できる。[CEDEC 2020 講演資料](https://www.jp.square-enix.com/tech/library/pdf/CEDEC2020_Manabe_%E8%87%AA%E5%B7%B1%E5%AF%BE%E6%88%A6%E3%81%A8%E5%BC%B7%E5%8C%96%E5%AD%A6%E7%BF%92%E3%81%AB%E3%82%88%E3%82%8BNPC.pdf)
- 公式大会出場者のコメントにブロックとウォールへの言及がある。[勇者杯2018夏](https://www.dragonquest.jp/rivals/yusha-hai/2018summer/players/)

第2弾までの収録では、武器の装備と耐久力、運命の分岐・未来視・未来の統合、終幕の一撃、山札の非公開選択、復活、変身、配置・列の指定、能力の付与を実装した。武器の置き換え時の破壊誘発、退場履歴の抽選、山札選択と同時誘発の順序など、一部の個別裁定は原作実機との突き合わせが残る。保存資料で版の異なる性能はカード別の対応表に記録した。

## 第3弾の物語の舞台

- 剣の紋章、魔法陣、祝福の地、安息の地は、ユニットがそのマスにいる間に働く。剣の紋章による武器ダメージと魔法陣による特技ダメージは、該当マスを占有するユニットの数に応じて増える。
- 滑走路、秘宝箱、危険床は、ユニットの配置と転位で反応する。占有中のマスにこれらの舞台を置いた場合も効果を解決する。既存の危険床を危険床に張り替えた場合は再び1ダメージを与える。
- 後衛の滑走路は同じ列の前衛ユニットの退場にも反応する。前衛が空いていれば、滑走路上の後衛ユニットがそのマスへ転位する。
- 導きの地は退場時の能力の後に処理する。山札から該当カードを得ると、該当カードに導きの地専用の能力があれば誘発する。該当カードが山札にない場合は、2018年の対戦記録に従い、カードを得ずに舞台が消える。後年の資料には別の処理の記載がある。[2018年の対戦記録](https://blog.livedoor.jp/deckkoutikucardgame/archives/2077647.html) · [後年の地形資料と画面](https://www.woodus.com/den/gallery/graphics/dqrivals/pdf/Dragon%20Quest%20Rivals%20Unique%20Terrains%20Guide.pdf)
- 種晶はコスト調整後の3MPを採用。種晶を設置したマスは上書きと破壊の対象外で、種晶カードの複製も不可。異なる6色をそろえた側が勝利し、その処理は同じカードのドローによる山札切れの敗北に優先する。[2019年の公式大会の記録](https://www.famitsu.com/news/201909/18183624.html)
- FT-0560とFT-0562は、保存画像の条件が重なるコスト4で両方の効果を解決する。コスト4の原作実機での処理は未確認。[FT-0560の原作画像](https://dqrdb.com/card/672.png) · [FT-0562の原作画像](https://dqrdb.com/card/719.png)
