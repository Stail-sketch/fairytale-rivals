# 第4弾『刻印に集う、おとぎの一族』の実装準備

2026年11月23日時点の調査。対象は原作第4弾『モンスターもりもり物語』。2018年8月24日の配信は[公式放送の告知](https://www.jp.square-enix.com/presents/info/20180817000717.html)で確認した。

候補一覧と確認状況は [fourth-pack-candidates.json](fourth-pack-candidates.json) に記録した。通常カード100種に FT-0575〜FT-0674 を予約している。童話戦記側の名称・素材・能力処理は実装工程で用意する。

## 確定したテーマと名称

| 項目 | 決定内容 |
| --- | --- |
| 童話戦記の第4弾パック名・テーマ | 刻印に集う、おとぎの一族 |
| 原作のパワフルバッジに対応する正式用語 | 物語の刻印 |
| 世界観の軸 | それぞれの一族に伝わる力を、語り手が刻印として受け継ぐ |
| カードの見せ方 | 一族の代表者、仲間を呼ぶ者、力を受け継ぐ者を名前・絵で表現する |

2026年11月23日にユーザーが採用を承認した。今後のカード効果文、能力の説明、UIでは「物語の刻印」を使う。

既存の10種族を土台に、一族ごとの象徴を衣装・武器・装飾へ取り入れる。象徴の形や色を関連するカードで共有し、デッキ編集中も仲間のつながりが伝わる絵を制作する。刻印を得る場面では、その象徴がリーダーの周囲に浮かび、取得済みの刻印と効果を確認できる表示へつなげる。

カードの性能と一対一対応は既存のマスター仕様に従う。一族の表現と、効果対象を判定する内部の系統情報を対応資料で追跡する。

## 共通能力の準備

| 項目 | 追加する処理 | 主な変更箇所 |
| --- | --- | --- |
| 物語の刻印 | リーダーが保持する効果の一覧。発生源の退場後の持続、重複、個別の除去、能力封じと復活からの再発動を照合する | エンジンのプレイヤー状態・効果解決・公開用状態 |
| 系統強化 | 既存の `family` を使った条件判定。場・手札・山札・装備を対象とする強化と、登場後に付く能力を処理する | コスト・攻撃力・最大HP・キーワードの計算 |
| ハードメタルボディに相当する能力 | 既存の鋼の身と併用できる軽減判定。5以下から1への軽減を画像と照合し、ダメージ予告と実ダメージに反映する | 防護判定・威力予告・盤面アイコン |
| 奥義の変更 | 現在の覚醒フラグに加え、カードから指定できる奥義IDを扱う。相手の事前確認、関連カード、CPUの判断にも反映する | `playerSkill`・奥義の合法手判定・UI |
| 連続した形態変化 | 退場後に次の形態が手札に加わる処理。形態ごとのカード定義と専用画像を持つ | 退場時能力・生成処理・関連カード |
| 4択の願いごと | 選択肢の非公開情報、未来の統合時の全効果解決、処理順と手札上限を扱う | 選択待ち状態・運命の分岐・オンライン同期 |
| 条件付きの支配・強化 | 発生源が場を離れた際の返却、追加された数値と既存の強化の持ち方を確認する | 支配権・効果の解除・ダメージ解決 |
| 履歴を使うカード | 退場した系統や壊れた武器を参照し、コスト・サーチ・回収に反映する | 退場履歴・装備破壊・山札選択 |

系統を軸に強化する設計と、場・手札・山札へ働くバッジについては、開発プロデューサーの説明を参照した。[配信時インタビュー](https://www.famitsu.com/news/201808/24162841.html)

既存の7人のリーダー、10種族、正式用語を基準に実装する。原作のスライム系・ドラゴン系・ゾンビ系・冒険者は、既存の内部分類 `slime`・`dragon`・`undead`・`adventurer` を使って扱う。「物語の刻印」以外の新能力で正式名称が必要なものは、個別に未確定として管理する。

## 実装順序

1. 100種の数値・レアリティ・効果を画像と照合し、版の相違と未確認の裁定を記録する。
2. 通常カードと生成カードを一対一で対応させ、童話戦記の名称と新規素材を用意する。
3. 物語の刻印、系統強化、軽減、奥義変更、形態変化、4択を共通能力として実装する。
4. 検証用の対戦で、能力の重複・除去・期限・処理順を確認する。
5. 通常カード100種と生成カードを追加し、職業・レアリティ別の収録数を照合する。
6. ライブラリ、デッキ編集、原作名検索、関連カード、用語ポップアップ、威力の加算表示、能力アイコンに反映する。
7. CPU戦とフレンド対戦で同じ結果になることを確認し、保存済みデッキと再戦にも対応する。

各カードの原作確認状況、実装状況、テスト状況、画像の準備状況を構造化データで個別に管理する。完了判定には通常カード100種の対戦使用と、必要な生成カード・選択肢の解決を含める。

## 優先して確認する対戦

- 物語の刻印の発生源が退場した後、手札や山札から使うカードにも効果が働く。
- 同じ効果を重ねた後に一つ取り除き、残りの強化を正しく再計算する。
- 元から能力を持つカードと、後から能力を得たカードの両方で数値・アイコンが一致する。
- 軽減と追加ダメージが重なる場合、予告値と実際のHP減少が一致する。
- 奥義が変わった後も、相手の能力確認とCPUの対象選択が正しい。
- 変身のたびにカード名・絵・関連カードが切り替わり、最後の形態まで処理できる。
- 通常の願いごとと全選択肢を使う場合の両方で、選択待ち・手札上限・勝敗を正しく扱う。
- フレンド対戦で双方の表示が一致し、再接続後も物語の刻印・奥義・形態を復元できる。
