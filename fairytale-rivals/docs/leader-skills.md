# 語り手の奥義とライバルズの参照先

通常対戦時の基本テンションスキルを参照し、必要な効果と生成カードを実装した。童話戦記の奥義名と生成カード名は新規。奥義は熱量3を消費する。各リーダーの詳細はゲーム内の「カードライブラリ」からも確認できる。

| 語り手 | 奥義 | 原作の参照先 | 本作の処理 |
| --- | --- | --- | --- |
| レオン・ド・ブーツ | 金剣の雷光 | 稲妻の加護 | 使用ターン中のリーダーに攻撃力+3と穿ちの一撃。攻撃先はプレイヤーが選び、通常の攻撃対象制限とユニットの反撃を適用 |
| アリス・ワンダー | 鏡炎の火球 | 紅蓮の火球 | 敵リーダーまたは選択可能な敵ユニット1体に3ダメージ |
| ルゥ・クリムゾン | 赤ずきんの型 | おてんば姫 | 1枚引いた後、3種類の武術から1枚を無作為に生成 |
| オーロラ・ソムニア | 花冠の祝祷 | いやしの波動 | 味方リーダーと全味方ユニットをそれぞれ3回復 |
| ジャック・グリーン | 豆の木の宝探し | お宝発見 | 3種類の道具から無作為に3枚生成 |
| スノウ・ミラー | 白銀の水晶 | 水晶占い | 山札から特技を1枚引いて、その札のコストを1下げる。特技がなければ鏡の審判を生成 |
| ヴァルド・ローゼン | 黒薔薇の騎士 | 魔族の騎士 | 味方の最初の空きマスに3/2の茨の騎士を召喚 |

基本効果は[スクウェア・エニックスのCEDEC講演資料（戦士・商人）](https://www.jp.square-enix.com/tech/library/pdf/CEDEC2020_Manabe_%E8%87%AA%E5%B7%B1%E5%AF%BE%E6%88%A6%E3%81%A8%E5%BC%B7%E5%8C%96%E5%AD%A6%E7%BF%92%E3%81%AB%E3%82%88%E3%82%8BNPC.pdf#page=5)と[当時の版の用語資料](https://www.woodus.com/den/gallery/graphics/dqrivals/pdf/Dragon%20Quest%20Rivals%20Ace%20Glossary.pdf)を参照。占い師は日本語の[通常対戦の効果・特技なしの場合の記録](https://kyokugen.info/dqr/dqr_leader06.html)に合わせた。CBT時点には軽減量が異なる[先行試遊の記録](https://gamebiz.jp/news/186417)がある。

## 原作で確認が残る裁定

- 空きマスがないときはヴァルドの奥義を使用不可とする。自動召喚は前衛の上から下、次に後衛の上から下。[当時の配置記録](https://dqr.playing.wiki/d/Tips)
- 武術・道具の無作為抽選は対戦シードを使う。本作では複数枚の道具をそれぞれ抽選し、同じ札も出る。蹴りは前後が埋まっていれば交換し、片側が空いていれば移動する。
- スノウの特技は条件を満たす札から無作為に1枚選ぶ。割引後は最低0。ほかの対象制限・誘発順・手札上限は本作の共通裁定を使用する。
- 奥義効果を更新した試遊版のリプレイはルール版 `prototype-2` を記録する。旧版の奥義を含むログの再現には作成時の試遊版を使用する。
