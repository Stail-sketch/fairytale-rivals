# 第4弾の制作原画

通常100種類＋生成・選択14種類のPNG原画114枚。[全画像ギャラリー](index.html)と[名前・制作指示](../../docs/fourth-pack-names-and-art.md)を参照。

各画像を内蔵ImageGenで別々に生成し、配信用WebPを `apps/web/assets` に組み込んだ。原画の再描画を行わず、サイズ・形式のみ変換した。

完全な生成プロンプト、参照原画、対応ID、SHA-256は `docs/fourth-pack-creative.json` に保存。`imports` の各JSONには配信用画像のハッシュと目視確認状態も記録する。変身後の4枚は、変身前の原画を参照して意匠を引き継いだ。

ゲーム用画像だけでなく、原画と制作指示もこのフォルダ・資料内で保持する。公開反映の状態は[権利確認記録](../../docs/fourth-pack-rights-review.md)を参照。
